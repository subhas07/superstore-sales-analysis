# Superstore Sales Analysis

An exploratory data analysis (EDA) project on the **Sample Superstore** retail dataset — 9,994 order-level transactions spanning 2014–2017 — uncovering sales and profit performance trends across products, regions, customer segments, discounts, and time.

## Project Description

This project performs an end-to-end EDA on a US-based retail superstore's transactional data to answer key business questions:

- What are the overall sales, profit, and profit margin?
- Which product categories/sub-categories/products drive profit — and which cause losses?
- How do sales and profit vary by region, state, customer segment, and shipping mode?
- How does discounting affect profitability?
- What do sales and profit trends look like over time (monthly, quarterly, yearly)?
- Which order-level factors correlate with profit?

The analysis concludes with a summary of key findings and business recommendations (e.g. capping discounts on loss-making sub-categories, addressing chronically unprofitable states, and focusing on Q4 seasonal demand).

## Dataset

- **Name:** Sample - Superstore
- **Source:** [Kaggle — Superstore Sales Dataset](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final) (also widely distributed as the sample dataset bundled with Tableau)
- **Size:** 9,994 rows × 21 columns (order-level transactions)
- **Key fields:** Order ID, Order/Ship Date, Ship Mode, Customer, Segment, Region, State, City, Category, Sub-Category, Product Name, Sales, Quantity, Discount, Profit
- `Superstore_Cleaned.csv` — the cleaned dataset (parsed dates + engineered features) exported at the end of the notebook

## Setup & Run Instructions

1. **Clone/download** this project folder and place `Sample - Superstore.csv` in the same directory as the notebook.
2. **Create a virtual environment** (recommended):
   ```bash
   python -m venv venv
   source venv/bin/activate      # on Windows: venv\Scripts\activate
   ```
3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
4. **Launch Jupyter Notebook:**
   ```bash
   jupyter notebook
   ```
5. Open `YourName_Superstore_Sales_Analysis.ipynb` and run all cells (**Kernel → Restart & Run All**).

   > Note: the notebook reads the file as `Sample - Superstore.csv` using `encoding='cp1252'`. Make sure the CSV file name/path matches, or update the `pd.read_csv(...)` cell if needed.

## Key Findings (Summary)

- **Total Sales:** $2,297,200.86 | **Total Profit:** $286,397.02 | **Overall Profit Margin:** 12.47%
- **Technology** is the most profitable category (17.4% margin); **Furniture** is the weakest (2.5% margin), dragged down by Tables and Bookcases, which post net losses.
- Discounts above ~30% are strongly associated with negative profit margins — at 80% discount, margin falls to **-180%**.
- The **West** and **East** regions are the strongest performers; **Texas, Ohio, and Pennsylvania** are the least profitable states despite meaningful sales volume.
- Sales and profit trend upward year over year (2014 → 2017), with **Q4 consistently the strongest quarter**.
